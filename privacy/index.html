Política de Privacidad

Transparencia, seguridad y protección de datos para los comercios y usuarios del Sistema de Control de Inventarios y Gestión Comercial.

Última actualización: 27 de Agosto de 2026

1. Responsable del Tratamiento de Datos

El Sistema de Control de Inventarios y Gestión Comercial Multi-Usuario es una plataforma SaaS desarrollada y operada por Emprendimiento JOSE HERRERA (en adelante "nosotros" o "la plataforma"), destinada a la administración de comercios, control de stock, facturación y reportes comerciales en tiempo real.

Esta Política de Privacidad describe cómo recopilamos, utilizamos, protegemos y compartimos la información personal y comercial que recibimos cuando los usuarios acceden y utilizan nuestro sistema web alojado en https://jesymca.github.io/inventario/.

2. Información que Recopilamos

Para la correcta prestación de nuestros servicios de gestión comercial, recopilamos los siguientes datos:

a. Datos de Autenticación de Google (OAuth 2.0)

Cuando te registras o inician sesión utilizando tu cuenta de Google, solicitamos acceso a la información básica de tu perfil público:

  • Nombre Completo: Para identificar al usuario propietario o administrador del comercio.
  • Correo Electrónico: Como identificador único de cuenta y canal de notificaciones administrativas.
  • Fotografía de Perfil (Avatar): Para la personalización visual de la interfaz.
  • ID de Usuario de Google: Para la verificación de token de inicio de sesión seguro.
b. Datos del Comercio y Configuración Comercial
  • Nombre del Negocio o Razón Social, Número de RIF / Identificación Fiscal.
  • Teléfono móvil / WhatsApp de contacto para pedidos y comprobantes.
  • Dirección física, redes sociales y logotipo del negocio.
  • Encabezados y pie de página personalizados para comprobantes y reportes en PDF.
c. Datos de Operaciones del Negocio
  • Catálogo de productos, precios al detal y al mayor, unidades por paquete, presentaciones y niveles de inventario.
  • Registro de ventas a clientes de contado o registrados.
  • Historial de compras a proveedores y movimientos de mercancía.
  • Comprobantes de pago de membresía adjuntados por los usuarios.

3. Cumplimiento con la Política de Datos de Google API

Declaración Requerida para Google OAuth:

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google por parte del Sistema de Control de Inventarios se adherirá a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use Requirements).

  • No vendemos datos de usuarios: Nunca vendemos, alquilamos ni comercializamos los datos obtenidos mediante Google OAuth a terceros.
  • No usamos datos para publicidad: No empleamos los datos de Google para fines publicitarios, creación de perfiles ni modelos de lenguaje externos.
  • Uso exclusivo para el servicio: La información recibida se utiliza estrictamente para autenticar al usuario y proporcionarle acceso a su propio panel de inventario y facturación.

4. Finalidad del Uso de la Información

La información recopilada es procesada exclusivamente para las siguientes finalidades legítimas:

  1. Autenticar de manera segura la identidad de los usuarios registrados.
  2. Generar e imprimir facturas, comprobantes de pago y reportes en formato PDF con la identidad gráfica de cada negocio.
  3. Calcular métricas comerciales, niveles de stock, ganancias y rendimiento de ventas por comercio.
  4. Gestionar el estado de la membresía mensual y notificar el período de uso activo del servicio.
  5. Brindar soporte técnico y atender incidencias reportadas por los administradores.

5. Almacenamiento, Infraestructura y Seguridad

Implementamos estándares de seguridad técnica y organizativa de primer nivel:

  • Base de Datos Relacional Encriptada: Los registros estructurados de usuarios, negocios, ventas y productos se almacenan en Turso DB (libSQL/SQLite) mediante conexiones cifradas HTTPS/TLS.
  • Almacenamiento de Multimedia en Cloudflare R2: Las imágenes de logotipos, productos y comprobantes se alojan en el servicio distribuido Cloudflare R2 Object Storage, organizadas en directorios seguros por cliente y optimizadas con compresión canónica previa.
  • Cifrado Local: El sistema hace uso de `localStorage` y `sessionStorage` únicamente para mantener tokens de sesión y cachés de rendimiento temporal.

6. Derechos ARCO (Acceso, Rectificación, Cancelación y Oposición)

Los usuarios conservan en todo momento la propiedad absoluta sobre los datos de su comercio y disponen de las siguientes facultades:

  • Acceso y Rectificación: Modificar los datos de su negocio, RIF, teléfono, catálogo de productos y precios directamente desde la sección "Perfil de Usuario & Negocio".
  • Portabilidad de Datos: Exportar su inventario completo y catálogo en formato CSV o JSON desde el módulo de importación/exportación.
  • Eliminación de Cuenta: Solicitar la eliminación definitiva de su comercio y registros asociados enviando una solicitud a nuestro canal de soporte.
